# Security policy

## Supported version

Athletica Log is maintained as a continuously deployed MVP. Security fixes target
the current version on the `main` branch and the production deployment.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting option in the repository's **Security** tab and
include the affected endpoint, expected impact, and reproducible steps where
possible.

Do not include real passwords, session cookies, invitation links, password-reset
links, or personal training data in a report. Reports will be acknowledged as soon
as practical and assessed before technical details are disclosed publicly.
